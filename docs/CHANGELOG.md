## How to use this file

Add entries under `[Unreleased]` as you ship things, grouped by:
- **Added** — new features
- **Changed** — changes to existing functionality
- **Fixed** — bug fixes
- **Removed** — removed features

When you feel like something is a meaningful checkpoint (not necessarily a formal release), you can cut a dated section, e.g.:

```
## [2026-07-01]

### Added
- Mobile: create habit flow
```
